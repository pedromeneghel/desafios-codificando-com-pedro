# Converter string para Camel Case

Complete o método/função para converter palavras delimitadas por hífen/underline/espaço para Camel Case. A primeira palavra na saída deve ser escrita em maiúscula somente se a palavra original já estiver em maiúscula (conhecido como Upper Camel Case, também frequentemente chamado de Pascal Case). As próximas palavras devem ser sempre escritas com a primeira letra em maiúscula.

## Exemplos
```
"the-stealth-warrior" é convertido para "theStealthWarrior"
"The_Stealth_Warrior" é convertido para "TheStealthWarrior"
"The_Stealth Warrior" é convertido para "TheStealthWarrior"
```
